# Formatting

- Sentences: 10 words or fewer
- Paragraphs: 3 sentences or fewer
- Sections: 4 paragraphs or fewer
- Lists: 4 words per item
- Tables: 3 columns or fewer, 3 words or fewer per cell
- Diagrams: 6 nodes, one per level
- Code Examples: Show relevant lines
- File references: Show brief inline code examples instead

# Explanation

- Simple
- Straightforward
- Minimal
- Coherent
- Avoid verbosity
