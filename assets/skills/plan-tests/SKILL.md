# Plan Tests

Plan tests for a selected function or class.

- Inspect behavior and relevant callers.
- Check nearby tests for conventions.
- Focus on observable outcomes.
- Suggest representative inputs and expected results.
- Include important edge cases and errors.
- Identify uncontrolled or nondeterministic inputs.
- Recommend ways to control relevant inputs.
- Avoid implementation-detail tests.
- Avoid redundant cases and brittle assertions.
- Do not write or edit tests.
- Return a concise test plan.
